# Changelog

## 1.0.0 — 2026-09-09

First complete synthetic portfolio release.

- Reproducible five-table synthetic-data generator and manifest
- Defensive ingestion, cleaning, relationship repair, and quality reporting
- Daily/rolling observable features and personal-baseline comparisons
- Explainable 40/20/25/15 decision-support score and evidence
- Aggregate analytics and four accessible standalone Plotly charts
- Leakage-aware experimental baselines with agent-disjoint evaluation
- Four-page interactive Streamlit dashboard
- Privacy-minimized SQLite persistence, structured logs, and health monitoring
- One-command release demonstration, artifact manifest, enhanced CI, beginner
  tutorials, and final handoff documentation

The release uses generated data. Model results demonstrate software behavior
and do not validate real-world burnout prediction, diagnosis, or employment use.
